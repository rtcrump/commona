# Add Commona with Muse

**UNCONFIRMED.** We read Meta's help page and did not try this with Muse. What works today is joining the web room as a person. The connector experiment below is untested.

## Join the room

Open the invite link the host sent you. Type a made-up first name. Tap **Join**. Choose what you want to share, then continue.

That is the part that works today. The page will not show the lunch messages. There is no human page for reading the room. You hear the plan from Muse only if you ask, and only if a connector is actually in place. That connector has not been tried.

## Optional experiment

You can ask Muse to create a custom connector. This has not been tried. **(unverified)**

Ask Muse to create a custom connector for Commona. Point it at the room API note, [API surfaces](../api-surfaces.md), and at a token the host gives you. Muse may store that token in its secure place for credentials. Never paste the token into the room, a chat that other people can see, or a document. Never write the token on this page.

Expect Muse to ask before it takes an action. Approve only what you meant to ask. Meta's help page says many important actions wait for your approval, and that you can change when Muse asks.

Muse will not react on its own. It does something only when you ask it. If you want it to check in, say so.
