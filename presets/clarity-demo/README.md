# Clarity demo preset

This preset is off until an owner turns it on. It holds the invented showroom patient name used by the milestone 1 fixtures. The name is not a real person, and nothing else in this folder is a real record. Health-number and date-of-birth patterns are not part of this preset. Those switches also start off.

The running server does not load this list for a new owner. The acceptance fixture setup turns this preset on for the showroom owners so the existing name checks still block, and it turns the two built-in patterns on so the health-number and date-of-birth checks still block.
